
# Rudransh Trading Academy

Premium, responsive, single-page financial education website.

**Developed by NEXOVA X | Built Beyond Limits**

## Project Overview

Rudransh Trading Academy is a financial education academy
located in Punpun, Patna, Bihar.

The website presents the academy's course curriculum and
allows students to prepare admission enquiries via WhatsApp.

## Technology Stack

- React.js
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP + ScrollTrigger
- Lucide React
- React Hook Form
- Zod
- GitHub
- Vercel

## Architecture

This is a strictly frontend-only website.

There is no:
- Database
- Admin panel
- Authentication
- Backend API
- CRM
- Supabase integration

Supabase is reserved for potential future requirements
and is not included in the current build.

## Course

Basic to Advanced Stock Market Course

Four curriculum modules:
- Basics of Stock Market
- Fundamental Analysis
- Technical Analysis
- Futures & Options

Course duration, fees, free demo and lifetime support
are intentionally not displayed pending approval.

## Development Setup

Requirements:
- Supported Node.js LTS release
- npm

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Check TypeScript:

```bash
npm run typecheck
```

Create production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## WhatsApp Enquiry

The student enters:
- Full name
- Mobile number
- Interested course
- Preferred batch
- Message

The form validates details and opens a WhatsApp message.

No enquiry data is stored on the website.
